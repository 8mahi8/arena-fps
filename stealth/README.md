# STEALTH DUEL（仮）｜3D潜入1vs1 試作

学校iPad（Safari）で友達と遊ぶ、3D・両者一人称・1vs1非対称潜入対戦の試作です。
ハンターは捕獲か時間切れ守備、侵入者は「装置4か所のうち2か所を起動 → 南側の2ゲートどちらかから脱出」で勝ち。試合は3分、音なしでも遊べる設計（接近は画面の赤い縁と矢印で表示）。

## 遊び方（オフライン・BOT戦）
- タイトルで「侵入者で遊ぶ」か「ハンターで遊ぶ」を選ぶ（相手はBOT）。
- 操作（タッチ）: 左スティック=移動、右半分ドラッグ=視点、「操作」長押し=装置の起動/捕獲/脱出、「ダッシュ」（侵入者）、「しゃがみ」（侵入者）。
- 操作（PC）: WASD＋マウス（クリックでポインターロック）、Space長押し=操作、Shift=ダッシュ、C=しゃがみ。

## オンライン対戦（部屋番号）
- 片方が「部屋を作る」（役割も選ぶ）→ 表示された5桁番号を友達に伝える → もう片方が番号を入れて「参加する」→ 部屋を作った側に「対戦開始」ボタンが出たら開始。
- 通信は Firebase Realtime Database（小国戦線IIIと同じDB・方式）。`/stealthRooms1v1` への読み書きは実DBで確認済みで、追加のルール設定は不要です。

## Google サイトへの貼り付け方
1. `stealth/dist/stealth-embed.html`（単体ファイル、約740KB）の中身を全てコピーする。
2. Google サイトの編集で「挿入 → 埋め込む → コードを埋め込む」に貼り付ける。
3. 埋め込み枠は横向きいっぱいに広げる（枠の大きさがそのままゲーム画面の大きさになります）。
- Three.js はファイル内に同梱済みで、外部から読み込むのは Firebase の2ファイルだけ（オンライン時のみ使用。オフラインBOT戦は通信なしで動きます）。

## 開発・ビルド
- 正本は分離ファイル: `stealth/index.html`、`stealth/src/core.mjs`（ゲームロジック）、`stealth/src/main.js`（描画・入力）、`stealth/src/net.js`（通信）。
- 単体HTMLの生成: `node stealth/build-embed.mjs`（要 `stealth/vendor/` の three.module.min.js / three.core.min.js）。
- テスト: `node --test "stealth/tests/*.mjs"`（コア9件＋通信フロー2件）。
- バランス検証: `node stealth/sim/simulate.mjs 200`（BOT同士の対戦。結果は `stealth/BALANCE.md`）。
- 設計判断の記録: `stealth/DESIGN.md`、調査: `research/RESEARCH_NOTES.md`。
