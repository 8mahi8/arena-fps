# STEALTH DUEL（仮）｜3D潜入1vs1 試作 v2.1

学校iPad（Safari）で友達と遊ぶ、3D・両者一人称・1vs1非対称潜入対戦の試作です。
舞台は夜の病院（64m×48m）。端末候補6台のうち有効なのは毎試合ランダムな4台で、侵入者は「探して2台起動 → 南の玄関ゲートから脱出」、ハンターは「捕獲か4分間の守備」で勝ち。音なしでも遊べる設計（接近は画面の赤い縁と矢印で表示）。

## v2のポイント
- **暗闇とライト**: 施設は暗く、奥を見るにはライトが要ります。ハンターのライトは赤色で常時点灯（光の漏れで居場所が推測できます）。侵入者のライトは任意オンオフ：点けると端末を遠くから発見できますが、ハンターからも遠くまで丸見えになります。
- **探索**: 侵入者は端末の場所を知りません。近づく（6m／ライト点灯中9m）＋視線が通ると発見し、ミニマップに記録されます。ハンターは全端末の位置を常時把握しています。
- **ミニマップ**: 右上に全体図。ゲートは常時表示、相手は表示されません。
- **隠れ場所**: ベッドや棚など遮蔽が多数。しゃがむと低い遮蔽の後ろではハンターの視線が切れます。さらにロッカー（7か所）に入って完全に隠れることもできます（ハンターが開けに来たら揺れで分かります）。
- **捕獲と注視（v2.1）**: 捕獲はボタンではなく接触式（1.4m以内で自動で溜まる）。ハンターが見つめ続けると「注視」が溜まり、満タンで20秒間「捕捉」状態になって捕獲がほぼ即決まります。視線を切れば注視は減ります。侵入者にダッシュはなく、逃走は視線切り・ロッカー・煙幕（初期1個＋補充1個）で行います。

## 遊び方（オフライン・BOT戦）
- タイトルで「侵入者で遊ぶ」か「ハンターで遊ぶ」を選ぶ（相手はBOT）。
- 操作（タッチ）: 左スティック=移動、右半分ドラッグ=視点、「操作」長押し=端末の起動/捕獲/脱出、「しゃがみ」「ライト」「煙幕」（侵入者）。
- 操作（PC）: WASD＋マウス、Space=操作、C=しゃがみ、F=ライト、G=煙幕。

## オンライン対戦（部屋番号）
- 片方が「部屋を作る」（役割も選ぶ）→ 表示された5桁番号を友達に伝える → もう片方が番号を入れて「参加する」→ 部屋を作った側に「対戦開始」ボタンが出たら開始。
- 通信はFirebase Realtime Databaseの `/stealthRooms1v1` を使用。既定のDBで読み書きできることをモカ側で確認済み。

## Googleサイトへの貼り方（本番・学校配布用）
1. `stealth/dist/stealth-embed.html` の中身を全部コピーする（Three.js同梱の単体HTML、約760KB）。
2. Googleサイトのページで「埋め込む」→「HTMLを埋め込む」に貼って保存。
3. 全画面に近い大きさの埋め込み枠を推奨。横向きで遊ぶ前提。
